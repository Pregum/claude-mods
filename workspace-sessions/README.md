# workspace-sessions

いま開いているワークスペース (git リポジトリの本体と、その worktree) で動いている・動いていた Claude Code のセッションを、`/ws` で開くペインに並べる mod。

## できること

- **並べる**: 動いているもの (端末の対話・バックグラウンド) → 止まったバックグラウンド → 過去のトランスクリプト の順。よそのリポジトリのセッションは出さない。選んでいる行には `›` が付く
- **のぞく**: `d` で詳細 (最後の依頼と最後の返答) を開け閉め。開いたまま `j` / `k` で動くと、移った先の詳細を出す
- **見る** (`o`): 一覧と入れ替えて、そのセッションの最近の依頼と返答 (16 発言まで、ツールの呼び出しは出ない) を見せる。5 秒ごとに読み直し、Esc か `q` で一覧へ戻る
- **送る**: 選んだ行で Enter (か `i`) を押すと、会話の下に送る欄が出る。打って Enter で送ると、続けて打てる。Esc で一覧へ戻る (`$.session.send`)
- **別で開く** (見ている間の `a`): バックグラウンドは `claude attach <id>`、過去のものは `claude --resume <id>`。cmux の中なら新しいワークスペースで開き、そうでなければコマンドをクリップボードへ。端末で動いているものには出ない
- **Web** (`w`): Remote Control がつながっているものは claude.ai/code で開く
- 一覧が開いている間は 20 秒ごとに描き直す
- 幅と高さはエンジンが許す最大で開く (ドックは端末の 45% まで。全画面にする口はエンジンに無い)

## キー (ペインにフォーカスがあるとき)

| キー | 動き |
| --- | --- |
| `j` / `k` | 次・前のセッションを選ぶ |
| `1`〜`9` | その行を選ぶ |
| `d` | 詳細の開け閉め (ctrl+o の代わり。ctrl+o はエンジンが会話の展開に使っている) |
| Enter (選んでいる行で) / `i` | 表示に入って送る欄を出す。止まっている行の Enter は詳細の開け閉め |
| `o` / `c` / `w` | 選んでいる行を 見る / コマンドをコピー / Web で開く |
| `r` / `p` / `q` | 更新 / 過去をすべて / 閉じる |
| ctrl+d / ctrl+u | 半ページ下・上へ (詳細を開いて長くなったとき)。PageDown / PageUp も半ページになる |

見ている間のキー:

| キー | 動き |
| --- | --- |
| Esc / `q` | 一覧へ戻る (送る欄で打ちかけた文は消える) |
| `i` | 送る欄を出す |
| `a` / `c` / `w` | 別で開く / コマンドをコピー / Web で開く |
| `r` | 読み直す |

プロンプトに文字が残っていると、エンジンがフォーカスを渡さないのでキーがプロンプトへ流れる。空にしてから `/ws` で開き直す。

### ctrl+d / ctrl+u を使うには

キーの割り当ては mod に入れられないので、`~/.claude/keybindings.json` の `Pane` context に足す (ペインにフォーカスがあるときだけ効く。プロンプトでの ctrl+d・ctrl+u はそのまま)。mod はこのペインのページ送りを半ページに縮める。

```json
{
  "$schema": "https://www.schemastore.org/claude-code-keybindings.json",
  "bindings": [
    { "context": "Pane", "bindings": { "ctrl+d": "pane:pageDown", "ctrl+u": "pane:pageUp" } }
  ]
}
```

ctrl+d は予約キーなのでデバッグログに `"ctrl+d" may not work` と出るが、割り当ては読み込まれる。

## どこから読んでいるか

| 何 | どこ |
| --- | --- |
| 動いているセッション・止まったバックグラウンド | `claude agents --json --all` |
| 過去のセッション | `~/.claude/projects/<ワークスペースのフォルダ>*/<id>.jsonl` (cwd で確かめる) |
| 題名 | トランスクリプトの `customTitle` / `agentName` / `aiTitle`、無ければ `~/.claude/history.jsonl` かトランスクリプトの最初の依頼 |
| Web のリンク | `~/.claude/sessions/<pid>.json` の `bridgeSessionId` |

## 確かめる

```sh
claude plugin validate .
claude plugin test .
```

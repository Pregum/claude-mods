# artifact-dates

Artifact を更新日でグループに分けて、会話の横のペインに並べる mod。`/artifacts-by-date` で開いてキーを渡す。

今日、昨日、今週、先週、そのあとは月ごとに分かれる。週は月曜から。

## 入れ方

ターミナルの Claude Code のプロンプトで:

```
/plugin install artifact-dates --marketplace Pregum/claude-mods
```

## キー

| キー | 動き |
| --- | --- |
| `1` / `2` | 自分 / 共有 |
| `j` / `k` (矢印も) | 次・前を選ぶ |
| Enter | ブラウザで開く。ペインは残る |
| `i` | 題名と URL をプロンプトの下書きに入れて閉じる。そのまま続きを頼める |
| `p` | 本文のプレビューを出す・消す。止まった行だけ読む |
| `c` | URL をコピー |
| `s` | 作った会話へ戻るコマンドをコピー |
| `f` | 題名とプロジェクト名で絞り込む。空白で区切ると全部の語を含むものだけ |
| `r` / `q` | 更新 / 閉じる |
| Esc | キーをプロンプトへ返す。ペインは残る |

## できないこと

- 読めるのは Artifact の一覧が返す、最近開いた・更新した 200 件まで。
- 一覧には時刻が無いので、日付までしか分からない。
- 共有分には日付が無いので、「日付なし」にまとまる。
- 作った会話は手元の履歴 (`~/.claude/projects`) から探す。消えた履歴や別の端末で作ったものは分からない。
- プレビューは自分の Artifact だけ。スクリプトで描くページは本文を取り出せないことがある。

一覧は Artifact ツールを `list` で呼んで読む。権限の設定によっては確認が出る。

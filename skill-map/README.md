# skill-map

スキル、コマンド、エージェント、plugin のつながりを有向グラフでペインに出す mod。`/skillmap` で開いてキーを渡す。

見たスキルから、付け替え、参照の削除、組み合わせの依頼をプロンプトに下書きできる。

```text
               ┌─◀▶[check-surveys]─┬─◀▶[survey-status]
[scan-surveys]─┴───────────────────┘

[add-whatsnew]───◀▶[publish-deck]───◀▶[add-tips]
```

## 入れ方

ターミナルの Claude Code のプロンプトで:

```
/plugin install skill-map --marketplace Pregum/claude-mods
```

## 見えるもの

- **全体図:** 開いているグループのつながりを、塊ごとに左から右へ描く。最初に開くのは「このプロジェクト」と「自分のスキル」
- **中心の図:** 選んだスキルを呼ぶ元と、呼ぶ先 2 段までを描く。参照している行とファイルのパスも出す
- **説明:** カーソルが当たっているスキルの説明を、図の上の枠に出す
- **本文:** 中心のスキルで Enter を押すと、ペインの中で読める

線の向きは次の通り。

| 線 | 意味 |
| --- | --- |
| `─▶` | 呼ぶ |
| `◀▶` | 相互に参照 |
| `─◀` | 右から左へ呼ぶ (循環している線) |

## キー

| キー | 動き |
| --- | --- |
| `j` / `k` (上下の矢印も) | ノードや行を上下に移動。本文ではスクロール |
| `h` / `l` | 左右の段へ移動。図が長いときは横にスクロール |
| Enter | 選んだスキルを中心にする。中心なら本文を読む。一覧ではグループを開閉 |
| `b` | 前のスキルへ戻る。絞り込みを解除 |
| `t` | グラフと一覧を切り替え。一覧で開いたグループが図に入る |
| `f` | 名前や説明で絞り込む |
| `o` | ファイルを開く (macOS の `open` を使う) |
| `r` | 中心のスキルが呼ぶ先を付け替える依頼を下書き |
| `x` | 中心のスキルから参照を外す依頼を下書き |
| `a` | 中心のスキルから別のスキルへつなぐ依頼を下書き |
| `m` / `c` | 印を付ける / 印を付けた順に呼ぶスキルを作る依頼を下書き |
| `u` | 読み直す |
| `i` | キー一覧の開閉 |
| `q` / Esc | 閉じる。入力中や本文では Esc で取り消す |

左右の矢印キーは、ペインの mod へ届かないので使えない。

## 編集のしかた

mod はファイルを書き換えない。依頼文をプロンプトに下書きするので、内容を確かめて送ると Claude が通常の承認付きで直す。

plugin と同期スキルは更新で上書きされるので、読み取り専用として扱い、`r` `x` `a` を受け付けない。plugin の on/off は表示だけ。

## つながりの見つけ方

開くたびに、次の場所の `SKILL.md`、コマンド、エージェントの Markdown を読む。

- このプロジェクトの `.claude/`
- `~/.claude/`
- 同期スキル
- 有効な plugin

本文にある名前からつながりを見つけるので、誤検出や見落としが残ることがある。

- `/名前`、`plugin:名前`、ハイフンを含む名前、`skills/名前/` のパスを参照として数える
- ハイフンのない一語の名前は、`/` や `スキル` などが付くときだけ数える
- 組み込みのコマンドは数えない
- 同名のスキルは、同じ出どころ、プロジェクト、ユーザー、同期スキルの順に探す。複数の plugin にあるときはつながない

14 件を超える塊と中心の図は木に絞るので、線の一部を省く。省いた本数は図の下に出る。

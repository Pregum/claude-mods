# where-now

いまどこまで進んだかを、会話の横のペインに出す mod。

- **全体マップ**: 幅いっぱいが 1 セッションのスコープ。依頼ごとの棒に、ツールの内訳が色で積まれる (緑 編集、黄 実行、青 調査、紫 委任、灰 会話)。高さは呼び出し数。選んでいる依頼の列は、フォーカス中に点滅する
- **compact**: 自動 compact が走る地点までの進み。右端の線がその地点で、近づくほど赤くなる。`あと` は残りのトークン数。自動 compact が切れているセッションでは、コンテキストウィンドウの使用率 (`文脈`) を出す
- **依頼の一覧**: 選んでいる依頼のまわりの 5 件
- **計画**: TodoWrite / TaskCreate / TaskUpdate / TaskList の内容と進み具合 (`▶` 進行中、`○` 未着手、`✓` 完了)
- **このターン**: 人の依頼が来てから Read / Write / Edit / NotebookEdit で触ったファイル (`●` 動作中、`✎` 書いた、`·` 読んだ、`✗` 失敗)。最後に触ったものが上。サブエージェントだけが触ったものには `sub` が付く

セッションの開始時に開く。幅が足りないと待つので、そのときは `/where` で開く。手で閉じると、次に `/where` で開くまで開かない。

## マップの操作

`/where` でペインにキーを渡す (`ctrl+x tab` でも移れる)。

| キー | 動き |
| --- | --- |
| `j` / `k` | 次・前の依頼を選ぶ |
| `g` / Enter (行で) | 会話のその依頼へ飛ぶ |
| `r` | `/rewind` を開く。途中の地点まで戻す |
| `b` | `/branch` で今の地点から分岐する |

途中の地点から直接 fork はできない。`--resume-session-at` は print mode 専用で、対話画面では効かない。途中から分けたいときは、`r` で戻す前に `b` で分岐しておく。

## 閉じる

| キー | 動き |
| --- | --- |
| `/where` / `ctrl+x w` | 開いてキーを渡す。出ていればキーを渡す |
| `q` | 閉じる (キーがあるとき) |
| Esc | キーをプロンプトへ返す。ペインは残る |
| `ctrl+x x` | 閉じる (キーがあるとき) |

プロンプトから一度でキーを渡したいときは `~/.claude/keybindings.json` に足す (キーの割り当ては mod に入れられない):

```json
{
  "bindings": [
    { "context": "Chat", "bindings": { "ctrl+x w": "command:where" } }
  ]
}
```

## 入れ方

ターミナルの Claude Code のプロンプトで:

```
/plugin install where-now --marketplace Pregum/claude-mods
```

## 出ないもの

Bash の `cat` や `sed` で読み書きしたファイルは出ない。コマンドの文字列から確実には読み取れないため。

全体マップの色は Bash の中身も見て分ける。読むだけのコマンドは調査、書くものは編集、それ以外は実行。文字列から推定するので目安。

スコープとゲージの絵は端末だけ。デスクトップなどでは 1 行の帯になる。

## 確かめる

